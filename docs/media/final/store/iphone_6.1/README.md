# Replacements for the existing iPhone screenshot slot

These are **two replacement images**, not a full screenshot set.

Replace current images **03** and **04** in App Store Connect's iPhone
6.1-inch display set with the matching PNGs in this folder. Keep the other
seven uploaded images and preserve numeric order 01 through 09.

Both images are rendered directly from build 33 source at **2622 × 1206**,
RGB without alpha; neither is a resized or painted-over image. The main
`iphone_6.9/` folder remains the complete nine-image set for the large
iPhone display slot. See `docs/submission33/README.md` for verification.
