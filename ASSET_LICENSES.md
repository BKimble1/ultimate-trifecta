# Asset and dependency provenance

Ultimate Trifecta uses no purchased assets, no asset-store packs, and nothing copied from Kerbal Space Program, Fall Guys, Stumble Guys, Brawl Stars or any real university. V2 studied those games only for general readability ideas, such as chunky silhouettes, one bold primary button, and calm HUD corners; every shape, colour, name and line of code is original. Everything visible or audible in the game is either generated by code in this repository or one of the openly licensed items listed below.
